# 🚇 Metro Map Generator

Инструмент для генерации, парсинга и обогащения данных схем метрополитена. Создаёт структурированные JSON-файлы карт с координатами станций, связями между ними и точным временем перемещения, извлекая данные из APK Яндекс.Метро или резервного API HeadHunter.

## ✨ Возможности

- 🌍 **Пакетная обработка** — генерация карт для всех доступных городов одной командой или выборочно по флагу.
- 🔗 **Унифицированный выход** — генерация единого формата `MapData`, совместимого с графовой моделью проекта, независимо от источника.
- 🏷 **Локализация** — извлечение названий станций и линий (поддержка `ru`, `en`, `be`).
- 🎨 **Цвета линий** — автоматическое извлечение HEX-цветов.
- 🛡 **Отказоустойчивость** — если для одного города не хватает данных, скрипт пропускает его и переходит к следующему.
- 🧩 **Масштабируемость** — добавление нового города = просто положить папку в `data/`.

---

## ⚙️ Требования

- **Go 1.21+**
- **Доступ к интернету** — только для fallback-режима. При наличии `data.json` работает офлайн.
- **Сырые данные** — файлы `data.json` и `l10n.json`.

## 🚀 Установка и запуск

1. Клонируйте репозиторий:

    ```bash
    git clone https://github.com/yourname/metro-map-generator.git
    cd metro-map-generator
    ```

2. Инициализируйте модуль (если ещё не сделан):

    ```bash
    go mod init metro-generator
    go mod tidy
    ```

3. Поместите файлы `data.json` и `l10n.json` в папку `cmd/mapgen/data/<city_name>/`:

    ```text
    cmd/mapgen/data/
    ├── minsk/
    │   ├── data.json
    │   └── l10n.json
    └── moscow/
        ├── data.json
        └── l10n.json
    ```

4. Запустите генератор:
    ```bash
    go run cmd/mapgen/main.go
    ```

## 🎛 Использование

### Генерация для конкретного города

```bash
go run cmd/mapgen/main.go -city minsk
```

### Пакетная генерация для всех городов

```bash
go run cmd/mapgen/main.go
```

Скрипт автоматически просканирует папку `cmd/mapgen/data/` и обработает все найденные подпапки.

### Доступные флаги

| Флаг                 | По умолчанию      | Описание                                                    |
| -------------------- | ----------------- | ----------------------------------------------------------- |
| `-city string`       | `""` (все)        | Название города (папки). Если не указан, обрабатываются все |
| `-data-dir string`   | `cmd/mapgen/data` | Путь к папке с сырыми данными                               |
| `-output-dir string` | `assets/maps`     | Путь для сохранения готовых карт                            |

### Пример вывода

```text
🏙  Обработка города: MINSK
  📦 Парсинг координат и времени...
  ⏱  Обновлено время для 87 рёбер.
  💾 Сохранено в: assets/maps/minsk/minsk.json (Узлов: 33, Рёбер: 45)
✅ Город minsk успешно обработан!
```

### Логика выбора источника

1. **Проверяем** наличие `data.json` в папке города.
2. **Если есть** → парсим (координаты + время).
3. **Если нет** → запрашиваем API (только координаты, время = 0).
4. **Если и API упал** → пропускаем город с предупреждением.
